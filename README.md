# 한끼온 (HANKEE ON)

> 혼자 사는 사람의 냉장고 재료를 끝까지 다 먹게 돕는 식생활 앱.
> 재료 → 오늘 한 끼 → 요리 → 재고 차감 → 기록을 **1인분 기준 한 흐름**으로 잇는다.

- 기술: React Native + Expo (SDK 58), Expo Router, TypeScript
- 저장: 기기 안(AsyncStorage). 무료 · 광고 없음 · 로그인·서버는 다음 단계
- 글꼴: Pretendard (SIL OFL 1.1, assets/fonts/Pretendard-LICENSE.txt)
- AI: Google Gemini(무료 등급, 사진 인식) — 키가 없으면 AI 기능만 꺼지고 나머지는 동작

## 왜 필요한가
- 1인 가구는 전체 가구의 36.1%(2024, 국가데이터처)이고, 줄이기 싫은 지출 1순위가 식비다.
- 재료는 가족용 대용량으로 팔려 혼자서는 다 쓰기 어렵고, 시들어 버려진다.
- 냉장고 앱은 유통기한 알림에서 끝나고, 레시피 앱은 내 냉장고와 1인분을 모른다.
- 자세한 분석: [docs/프롬프트_경쟁분석과개선.md](docs/프롬프트_경쟁분석과개선.md)

## 주요 기능
| 영역 | 기능 |
|---|---|
| 홈 | 손그림 냉장고 + 캐릭터, 오늘 먼저 쓸 재료 수, 오늘 한 끼 카드, **끼니 전 '집밥·외식·간단히' 선택**(외식·편의점이면 고르는 기준 + 곧 상할 재료는 내일 집밥으로), 알림은 가장 급한 것 하나만 |
| 냉장고 | 냉장·냉동·실온 선반, 빠르게 고치기, **저울 없이 '반쯤·조금' 눈대중 양**, 재료 151개 보관 정보(냉장·냉동·실온 기간, 상한 신호), 소분·냉동 옮기기, 일주일 30초 점검 |
| 재료 등록 | 이름만 적어도 등록, 자주 넣는 재료 칩, 흔한 포장 크기 버튼, 사진 인식(AI) |
| 메뉴 | 레시피 69개, **종류 8칸 격자 + 상황 칩**(15분 컷·도시락·가볍게·야식·든든하게·도전), 추천 3개씩과 이유 한 줄, 냉장고 털기, 즐겨찾기 |
| 레시피·요리 | 재료 꺼내기(먼저 쓸 것부터), 보관·안전(식약처 기준), 미리 해 둘 일, 요리 모드(타이머 여러 개), 완료 후 재고 차감·식사 기록·남은 음식, **남은 재료로 내일 메뉴 이어주기** |
| 식단·장보기 | 오늘·7일 식단, 부족 재료 담기, 매장 코너별 정리, **1인 구매량 조언**, 산 재료 한 번에 냉장고로 |
| 기록·리포트 | 끼니별 기록(집밥·배달·외식·편의점, 금액), 어제와 같게, 주간 회고, 재료별 산 것·버린 것, 식비 목표 |
| 설정 | 요약 목록 + 하나씩 고치기, 생활 유형으로 자동 채우기, 알레르기·기피 음식 제외, 백업·불러오기, 시연용 장면 6가지 |

## 데이터 근거
- 영양: 식약처 식품영양성분 DB(공공데이터포털) — 레시피 33개 연결, 나머지는 '추정' 표시. 대조표 [docs/출처기록.md](docs/출처기록.md)
- 보관: 식약처 보관 안내·USDA FoodKeeper 범위 중 짧은 쪽. 화면에 "포장지 소비기한이 먼저"
- 안전: 고기·해산물 중심 75℃ 1분 이상, 조리 음식 2시간 안에 냉장(식약처)
- 레시피 사이트는 비교용으로만 쓰고 글·사진은 가져오지 않는다

## 실행

```bash
npm install
npx expo start          # 휴대폰의 Expo Go 앱으로 QR 스캔
npx expo start --web    # 브라우저에서 보기
```

AI를 켜려면 `.env.example`을 `.env`로 복사하고 `EXPO_PUBLIC_GEMINI_API_KEY`를 채운 뒤 다시 실행한다.

## 점검 명령
```bash
npx tsc --noEmit --noUnusedLocals   # 타입
npx expo lint                       # 코드 검사
npm run check:data                  # 레시피·재료 데이터 규칙(재료↔순서, 시간, 분류, 보관·안전 정보)
npm run data:nutrition              # 식약처 영양 DB로 영양값 다시 만들기(.env에 DATA_GO_KR_KEY 필요)
```

## 폴더 구조

```
src/
  app/                화면(파일 하나 = 화면 하나)
    (tabs)/           하단 탭: 홈 · 메뉴 · 추가 · 기록 · 나
    recipe/[id]       레시피(재료 꺼내기·보관·안전)
    cook-mode/[id]    요리 모드(단계·타이머)
    cook/[id]         요리 완료(재고 차감 + 식사 기록)
    fridge, plan, shopping, report, goals, settings, onboarding, menu-deck, scan/
  data/               타입, 저장소(store), 레시피·재료 사전·보관 정보·분류·영양 DB, 시연 데이터
  logic/              계산: 재고↔레시피, 추천, 식단, 눈대중 양, 구매량, 끼니 선택, 분석
  components/         공용 부품(ui.tsx 버튼 3종 등), 홈·카드 부품
  constants/tokens.ts 디자인 토큰(색·간격·글자)
scripts/              데이터 점검·공공데이터 가져오기
docs/                 기능현황, 개선목록, 프롬프트, UX/UI 방향, 출처기록
```

구현 상태는 [docs/기능현황.md](docs/기능현황.md)를 본다.
