## 실행 프롬프트
```
한끼온(~/Desktop/창업아이템/hankee-on) 야간 자동 작업이야. 나는 자고 있으니 묻지 말고 아래 순서대로 끝까지 진행해.
docs/프롬프트_야간자동작업.md의 N1~N9를 순서대로 해.

규칙
- 스킬을 따른다: 시작·확인은 hankee-sim-check, 항목마다 마무리는 step-finish, 데이터는 data-accuracy.
- 항목 하나 끝날 때마다: tsc·lint·check:data 통과 → 화면이 바뀌면 시뮬레이터 스크린샷(데이터/스크린샷/2026-11-25_야간/) → 작업일지 → 한국어 커밋·푸시.
- 기존 기능을 깨지 않는다. 새 탭·새 화면·새 라이브러리 없음. 저장 데이터 구조는 선택값 추가만.
- 설치·삭제·비용·외부 발송·로그인이 필요하면 그 항목은 건너뛰고 '아침 확인 목록'에 적는다.
- 고치지 못한 버그나 판단이 필요한 것도 건너뛰고 '아침 확인 목록'에 적는다. 한 항목에 1시간 넘게 막히면 다음으로.
- 시연용 데이터는 마지막에 장면 '기본' + 저녁 '집밥'으로 되돌려 둔다.

끝나면
- docs/아침확인.md에: 한 일(커밋 해시), 스크린샷 목록, 건너뛴 것과 이유, 내가 결정할 것(보기 2~3개와 추천).
- 마지막 보고는 쉬운 한국어로 짧게.
```
