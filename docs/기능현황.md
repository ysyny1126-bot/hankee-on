# 오잘먹 기능 현황

기준일: 2026-11-18(2차) · 마감: 2026-11-25

화면 구조는 docs/화면설계.md 참고. 탭: 홈 · 요리 · ⊕ · 기록 · 나.

표시: ✅ 실제 작동(데이터 연결, 브라우저에서 확인) · 🔑 코드 완성, AI 키 연결 후 확인 필요 · 🖼️ 화면만 · ⏳ 미구현

## 데이터 흐름 (핵심 연결)

```
식재료 등록(사진/직접/장보기 구매) → 냉장고 재고 ─┬→ 소비기한 임박 → 홈 제안·휴대폰 알림
                                                 ├→ 레시피 추천(보유율·임박 재료·알레르기 제외)
                                                 └→ 식단 짜기(7일)
레시피 → 부족 재료 → 장보기 목록 → 구매 완료 → 재고 등록
레시피 → 요리 완료 → 재고 차감 + 요리 기록 + 식사 기록
식사 기록 → 식생활 분석·리포트·목표 진행률 → 다음 식사 제안(기억하는 AI)
```

모든 화면이 `src/data/store.tsx` 하나의 저장소를 같이 쓰므로 한 번 입력한 데이터를 다시 입력하지 않는다.

## 1순위: 핵심 기반

| 기능 | 상태 | 비고 |
|---|---|---|
| 온보딩(취향·알레르기·조리시간·예산·동의 3종) | ✅ | |

| 소비기한 입력(직접, 빠른 날짜) | ✅ | 앱이 날짜를 추측하지 않음 |

| 음식 사진 → AI 레시피 | 🔑 | 생성 후 레시피 화면으로 이어짐 |

| 식사 기록(음식명, 끼니, 시간, 분량, 집밥/배달/외식/편의점, 메모, 수정·삭제) | ✅ | |
| 식사 사진 → AI 음식·영양 추정 | 🔑 | 사진 저장은 키 없이도 됨 |

## 알려진 한계 · 출시 전 할 일

- **AI 키 보안:** 지금은 앱에서 Gemini로 바로 요청 → 출시 전 서버(Supabase Edge Function 등)를 거치게 바꿔야 함.
- **무료 AI 약관:** 무료 등급은 입력 데이터가 구글 서비스 개선에 쓰일 수 있음 → 출시 땐 유료 등급.
- **사진 저장:** 휴대폰의 임시 사진 경로만 저장 → 앱 재설치 시 사진이 사라질 수 있음.
- **영양값:** 기본 데이터는 일반적인 1인분 대략치. 화면에 항상 '추정'으로 표시.
- **lint:** `npx expo lint`는 ESLint 설치가 필요해 아직 안 돌림. 타입 검사(`npx tsc --noEmit`)는 통과.
