# 경쟁 분석 · 개선 목록 · 실행 프롬프트

> 2026-11-24 작성. 조사: 앱스토어 냉장고 관리 앱(냉장고 지킴이, 유통기한 언제지, 냉털이, Pantry, Fridgely, NoWaste, FridgeLoop 등)의 소개·리뷰, 만개의레시피 '냉장고 파먹기' 소개, 1인 가구 통계 기사.
> 리뷰 수가 적은 앱이 많아 **체계적인 조사가 아니라 경향 파악**이다.

---

## 1. 한끼온이 필요한 이유
1. **1인 가구가 가장 큰 가구 형태다.** 2024년 1인 가구는 804만 5천 가구로 전체의 36.1%다(국가데이터처 '2025 통계로 보는 1인 가구', 세계일보 보도).
2. **식비를 가장 지키고 싶어 한다.** 소득이 줄어도 마지막까지 유지하고 싶은 소비 1순위가 식비(42.5%)다(KB금융 '2026 한국 1인 가구 보고서', 보도 인용).
3. **재료가 남아서 버려진다.** 식재료는 가족 단위 대용량으로 팔리는데 혼자서는 다 쓰기 어렵다. 그래서 냉장고 한쪽에서 시들어 버려진다(기사·체험기).
4. **지금 앱들은 '관리'와 '요리'가 따로 논다.** 재고 앱은 유통기한 알림에서 끝나고, 레시피 앱은 내 냉장고 양을 모르고 4인분 기준이다. 한끼온은 **재고 → 오늘 한 끼 → 요리 → 재고 차감 → 기록**을 1인분 기준 한 흐름으로 묶는다.

## 2. 유사 앱·사이트의 부족한 점(조사에서 반복된 것)
| # | 아쉬운 점 | 근거(경향) | 한끼온 지금 |
|---|---|---|---|
| G1 | **처음 입력·계속 갱신이 귀찮아서 그만둔다** | "다시 하기 싫을 만큼 지루했다", "하나하나 같은 화면으로 처리해야 한다"(해외 앱 리뷰) | 직접 추가·빠르게 고치기·눈대중 양·장보기→냉장고 있음. **자주 사는 재료를 한 번에 넣기는 없음** |
| G2 | **재고가 실제와 어긋나면 믿지 않게 된다** | 갱신 부담 → 목록이 틀어짐 → 이탈 | 냉장고 확인 카드(기한 지난 것)만 있음. **정기 점검 흐름 없음** |
| G3 | **데이터를 잃을까 걱정한다** | "버그로 재고가 다 사라졌다, 다시 만드는 데 몇 시간"(NoWaste 리뷰) | 백업 기능은 있지만 **언제 했는지 모르고, 알려 주지 않음** |
| G4 | **유료 구독·광고·추적** | 핵심 기능 구독 잠금(Pantry), 추적 데이터 고지(냉털이) | 무료·광고 없음·이 기기 저장이지만 **처음 쓰는 사람에게 말해 주지 않음** |
| G5 | **레시피 앱은 1인분·남는 재료를 모른다** | 4인분 기준, 냉장고 차감 없음, 만들고 남은 재료 다음 활용 안내 없음 | 1인분·차감 있음. **요리 후 '남은 재료로 다음 끼니' 이어주기 없음** |
| G6 | **대용량 포장 문제를 해결해 주지 않는다** | 1인 가구 낭비의 주원인이 대용량 포장 | 장보기 목록은 있지만 **얼마나 사야 하는지 조언 없음** |
| G7 | 보관 장소·알림이 경직됨 | 냉장고 밖 수납장, 알림 시점 고정 불만 | 실온(찬장) 보관·알림 일수 설정 **이미 있음** → 할 일 없음 |

## 3. 개선 목록(기존 기능을 해치지 않고, 화면을 늘리지 않는 것만)
**복잡도 규칙**: 새 탭·새 화면 없이 **기존 화면에 줄 1개 또는 버튼 1개**만 더한다. 이 규칙을 못 지키면 목록에서 뺀다.

| 우선 | 개선 | 해결하는 문제 | 들어갈 자리 | 더하는 것 |
|---|---|---|---|---|
| P1 | **자주 넣는 재료 한 번에** — 최근·자주 등록한 재료 6개 칩, 누르면 지난번 양·단위로 바로 등록 | G1 입력 부담 | 재료 등록 화면 맨 위 | 칩 한 줄 |
| P1 | **남은 재료 이어주기** — 요리 완료 후 "남은 대파 0.5대 → 내일 계란국 어때요?" | G5 남는 재료 | 요리 완료 화면 저장 뒤 알림 문구 | 한 줄 + 버튼 1개(식단에 넣기) |
| P1 | **일주일 30초 점검** — 마지막 점검 7일 지나면 홈 냉장고 확인 카드에 '이번 주 점검' 한 장, 재료마다 [그대로·줄었어요·다 썼어요] | G2 재고 신뢰 | 기존 냉장고 확인 카드 재사용 | 카드 상태 1개 |
| P2 | **1인 구매량 조언** — 장보기 항목에 "이번 주 식단에 쓸 양 150g · 작은 팩이면 충분해요" | G6 대용량 | 장보기 항목 아래 | 회색 한 줄 |
| P2 | **백업 안심 표시** — 설정 '앱' 줄에 '마지막 백업 ○일 전', 30일 넘으면 홈 카드 아래 한 번만 알림 | G3 분실 걱정 | 설정 요약 줄·홈 | 문구 1개 |

## 4. 실행 프롬프트

### 역할
너는 1인 가구 식생활 앱 '한끼온'(Expo/React Native, Expo Router, AsyncStorage)의 UX 디자이너 겸 개발자다.
위 '개선 목록'의 P1 → P2를 순서대로 구현한다.
목표는 **입력을 줄이고, 재고를 믿을 수 있게 하고, 남은 재료를 다음 끼니로 잇는 것**이다.

### 지켜야 할 것
1. **기존 기능을 깨지 않는다.**
   - 지금 있는 화면 흐름(홈 → 메뉴 → 레시피 → 요리 → 기록), 데이터 구조, 저장 키(`hankeeon.state.v1`)를 유지한다.
   - 새 필드는 선택값(optional)으로 넣고 `migrate()`에서 기본값을 준다.
2. **화면을 늘리지 않는다.**
   - 새 탭이나 새 화면을 만들지 않는다.
   - 항목마다 기존 화면에 줄 1개 또는 버튼 1개만 더한다.
   - 한 화면에 새로 생기는 선택지는 3개 이하로 한다.
3. **정확성**
   - 소비기한은 앱이 추측하지 않는다(기존 원칙).
   - 구매량 조언은 식단에 실제로 잡힌 양만 더해 계산한다. 근거가 없으면 문구를 보여 주지 않는다.
4. **문구는 짧고 쉬운 말로** 쓴다. 한 줄에 정보 하나만 담는다. 꾸짖는 말투("또 버렸어요")는 쓰지 않는다.
5. **새 라이브러리를 설치하지 않는다.** 꼭 필요하면 먼저 묻는다.

### 항목별 구현 지시
1. **자주 넣는 재료 한 번에** (`src/app/ingredient/edit.tsx`)
   - 기존 재료·지출 기록에서 최근 30일 등록 횟수 순으로 6개를 고른다.
   - 지금 냉장고에 넉넉히 있는 재료는 뺀다.
   - 칩을 누르면 지난번 양·단위·보관 방법을 채운다. 사용자가 '등록'을 누르면 등록한다. 바로 등록하지 않고, 확인 한 번을 둔다.
   - 기록이 없는 새 사용자에게는 칩 줄을 숨긴다.
2. **남은 재료 이어주기** (`src/app/cook/[id].tsx` 완료 처리 뒤)
   - 차감한 뒤 남은 양이 '조금' 이하인 재료 중, 그 재료를 쓰는 다른 레시피를 1개 고른다(`rankForUser` 재사용).
   - "남은 ○○ → 내일 □□ 어때요?" 한 줄과 [식단에 넣기] 버튼을 띄운다.
   - 후보가 없으면 아무것도 띄우지 않는다.
3. **일주일 30초 점검** (`src/components/tidy-card.tsx`)
   - `preferences.lastCheckAt`(선택값)을 둔다. 7일이 지나면 카드 제목을 '이번 주 냉장고 점검'으로 바꾼다.
   - 기한 순으로 재료를 최대 5개 보여 주고, 버튼 3개를 둔다.
     - 그대로: 아무것도 안 바꿈
     - 줄었어요: 눈대중 한 단계 낮춤(`lowerLevel` 재사용)
     - 다 썼어요
   - 끝나면 `lastCheckAt`을 오늘로 둔다. 되돌리기(UndoToast)는 그대로 쓴다.
4. **1인 구매량 조언** (`src/app/shopping.tsx`)
   - 장보기 항목이 이번 주 식단 레시피에서 온 것이면, 그 레시피들의 필요량 합을 '이번 주에 쓸 양'으로 보여 준다.
   - 흔한 포장 크기(`packSizes`)보다 많이 작으면 '작은 팩이면 충분해요 · 남으면 냉동 보관' 한 줄을 붙인다.
5. **백업 안심 표시** (`src/app/settings.tsx`, 홈)
   - `preferences.lastBackupAt`을 백업 내보내기 때 기록한다.
   - 설정 '앱' 줄에 '마지막 백업 ○일 전 / 아직 안 함'을 표시한다.
   - 30일이 지났거나 아직 안 했으면, 홈에서 재료가 10개 이상일 때만 한 번 안내한다. 닫으면 30일 동안 다시 보이지 않는다.
6. **약속 한 줄** (`src/app/welcome.tsx`): 첫 화면 설명 아래에 "무료 · 광고 없음 · 내 기록은 이 휴대폰에만 저장돼요"를 넣는다.

### 확인과 기록
- `npx tsc --noEmit --noUnusedLocals`, `npx expo lint`, `npm run check:data`를 통과시킨다.
- iOS 시뮬레이터에서 항목마다 스크린샷을 찍어 사용자에게 보낸다. 빈 사용자와 예시 데이터 둘 다 확인한다.
- 기존 흐름 회귀 확인: 재료 등록 → 메뉴 → 요리 → 완료 → 기록이 전처럼 되는지 한 번 끝까지 눌러 본다.
- 항목마다 작업일지를 쓰고 커밋·푸시한다(한국어 메시지).

### 하지 말 것
- 새 탭·새 화면·팝업 연속, 랭킹·커뮤니티·광고
- 소비기한 자동 추측, 근거 없는 구매량 숫자
- 기존 필드 이름 변경·삭제(저장된 데이터가 깨짐)
