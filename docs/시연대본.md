# 오잘먹 3분 시연 대본(초안)

> 준비: 설정 → 데이터 관리 → 시연용 장면 **'기본'**, 홈 끼니 선택 **'집밥'**. 휴대폰(또는 시뮬레이터) 화면 공유.
> 말은 짧게, 화면이 말하게. 괄호는 누를 곳.

## 0:00 — 문제 (20초)
"혼자 살면 장을 봐도 재료가 남아요. 대파 한 단, 두부 한 모를 다 못 쓰고 버리죠.
냉장고 앱은 유통기한만 알려 주고, 레시피 앱은 4인분에 내 냉장고를 몰라요.
오잘먹은 **내 냉장고 재료로 오늘 한 끼**를 정해 주고, 끝까지 다 먹게 돕습니다."

## 0:20 — 홈 (40초)
- 손그림 냉장고: "오늘 먼저 쓸 재료 3개. 냉장고 문에 실제 내 재료가 붙어 있어요."
- 오늘 한 끼 카드: "두부·돼지고기가 곧 기한이라 두부김치를 추천해요. 이유도 한 줄로."
- (**외식**) "오늘 밖에서 먹는다면? 고르는 기준과, 오늘까지인 재료는 **내일 집밥으로** 넘겨 줘요." → (**집밥**)으로 되돌리기
- 아래 알림 카드는 **가장 급한 것 하나만** 보여 줘요.

## 1:00 — 메뉴 고르기 (30초)
- (메뉴 탭) "뭐 먹고 싶은지 칸에서 골라요." (**밥·덮밥**) → (**15분 컷**)
- "추천은 3개씩, 왜 추천하는지 한 줄. 알레르기 음식은 처음부터 빠져요."

## 1:30 — 요리 (40초)
- (레시피) "재료 꺼내기: 기한이 가까운 것부터. 보관·안전 정보는 식약처 기준."
- (요리 시작) 단계 화면·타이머 → 마지막 단계 익힘 안전 팁
- (완성) "저울 없이 '레시피만큼·덜·더'만 고르면 냉장고에서 빠지고, 식사 기록도 자동."
- 이어주기 팝업: "남은 대파 반쯤 → 내일 계란볶음밥 어때요?" (**내일 식단에 넣기**)

## 2:10 — 냉장고·장보기 (30초)
- (냉장고) "양은 '반쯤·조금'으로 눈대중. 재료마다 보관 기간과 상한 신호."
- (장보기) "식단에서 부족한 것만 담고, **1인분이면 작은 팩이면 충분해요**까지 알려 줘요."

## 2:40 — 마무리 (20초)
- (기록 탭 → 리포트) "이번 주 집밥 횟수, 식비, 버린 재료가 쌓여요."
- "무료, 광고 없음, 기록은 내 휴대폰에만. 다음은 로그인·영수증 인식·손그림 아이콘입니다."

## 예상 질문
- **데이터 정확해요?** 영양은 식약처 영양성분 DB 33개 연결, 나머지는 '추정' 표시. 레시피 69개는 자동 점검(재료↔순서·시간·분류·안전) 통과.
- **입력이 귀찮지 않나요?** 이름만 적어도 등록, 자주 넣는 재료 칩, 포장 크기 버튼, 눈대중 양, 장보기 → 냉장고 한 번에.
- **AI는?** 사진 인식(냉장고·포장지·음식)은 Gemini 키가 있을 때만. 없어도 모든 흐름이 동작.
