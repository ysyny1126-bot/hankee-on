# UX/UI 개선 방향(제안)

> 2026-11-24. iOS 시뮬레이터로 화면을 직접 눌러 보며 정리. 레퍼런스는 **원리만** 참고하고 그대로 옮기지 않는다.

## 지금 화면에서 보이는 문제(심한 순)
| # | 문제 | 어디서 보이나 |
|---|---|---|
| U1 | **떠 있는 파란 설정 버튼**이 모든 화면 오른쪽 위를 가린다. 브랜드 초록과 색이 충돌하고, '기록 전체 보기' 같은 글자를 덮는다 | 전 화면 |
| U2 | **이모지 아이콘이 들쭉날쭉**하다. 두부 = 버터, 김치 = 상추, 비빔밥 = 젓가락처럼 맞지 않고, 기기마다 모양이 다르다. 손그림 냉장고(FridgeArt)와 톤도 다르다 | 냉장고·레시피·메뉴 카드 |
| U3 | **회색 안내 문장이 많다.** 화면마다 소개 한 줄, 칸마다 설명, 카드마다 보조 문구가 있어 읽을 게 많다 | 등록·설정·장보기·레시피 |
| U4 | **홈이 길다.** 그림 → 집밥 진행 → 오늘 메뉴 → 기록 → 안내 카드 → 먼저 쓸 재료 → 오늘 식사 → 바로 가기 순으로 8단 | 홈 |
| U5 | **모든 카드가 같은 무게**(흰 카드 + 같은 둥근 모서리)라 어디를 먼저 봐야 할지 약하다 | 홈·식단·냉장고 |
| U6 | 버튼 모양이 섞여 있다(채움·테두리·글자만·칩). 같은 '보조 행동'인데 화면마다 다르다 | 요리 완료·확인 카드 |
| U7 | 레시피에 **음식 그림이 없다**(이모지 하나). 먹고 싶게 만드는 힘이 약하다 | 레시피·메뉴 카드 |

## 추천 방향: "손그림 부엌, 한 화면 한 가지"
홈의 손그림 냉장고가 가장 한끼온다운 요소다. 이 톤으로 나머지를 통일하고, 화면마다 주인공을 하나로 줄인다.

1. **설정 버튼 정리(U1)**: 떠 있는 버튼을 없애고 '나' 탭 맨 위 줄로 옮긴다. 정 필요하면 헤더 안 작은 회색 톱니로 둔다.
2. **아이콘 한 벌(U2)**
   - 재료·음식 아이콘을 FridgeArt와 같은 굵기의 손그림 선 아이콘으로 통일한다. react-native-svg로 그리며, 우선 자주 나오는 30개부터.
   - 그 외 재료는 분류 아이콘(채소·고기·유제품…)으로 대신한다.
3. **안내 문장 절반으로(U3)**
   - 처음 한 번만 보이는 도움말로 바꾼다. 다시 보기는 물음표.
   - 칸 설명은 placeholder로 옮긴다.
4. **홈 3단 구조(U4)**
   - ① 오늘(그림 + 오늘 한 끼 카드 + 먹은 것 기록 버튼)
   - ② 알려 줄 것 1개: 정리·점검·백업 중 가장 급한 하나만
   - ③ 이번 주(요일 줄 + 바로 가기)
   - 나머지는 다른 탭에서 본다.
5. **위계 3단계(U5·U6)**
   - 주인공 카드: 초록 배경 1개
   - 일반 카드: 흰색
   - 안내: 배경 없이 글자만
   - 버튼도 3종(주요=초록 채움, 보조=테두리, 약한=글자)으로 고정하고 칩은 고를 때만 쓴다.
6. **먹고 싶게(U7)**
   - 레시피 위쪽에 큰 손그림 일러스트를 두고, 배경색은 음식 색(찌개=주황, 샐러드=연두)에서 뽑는다.
   - 사용자가 찍은 사진이 있으면 그걸 우선 보여 준다.
7. **작은 반응**: 체크·완료 때 가벼운 진동과 캐릭터 표정 변화, 숫자가 바뀔 때 짧은 애니메이션을 준다.

## 참고할 레퍼런스(무엇을 볼지)
| 레퍼런스 | 볼 것 | 가져오지 않을 것 |
|---|---|---|
| 토스 | 한 화면 한 질문, 큰 숫자 하나, 넉넉한 여백 | 파란색, 금융 톤 |
| Apple 건강·피트니스 요약 | 오늘 요약 카드 1장에 핵심 숫자만, 링 진행 | 링 그래픽 그대로 |
| 핀치(Finch)·듀오링고 | 캐릭터가 칭찬·반응하는 피드백, 꾸짖지 않는 말투 | 게임 화폐·연속 기록 압박 |
| Mealime·Kitchen Stories | 레시피 단계 화면의 큰 글자, 재료 체크, 음식 이미지가 주인공 | 사진 스타일·영문 구성 |
| 당근 | 회색 문장 없이 아이콘 + 짧은 라벨, 탭 구조 단순함 | 주황색 |
| 오늘의집 | 따뜻한 베이지·일러스트 톤, 카드 여백 | 커머스 배너 |

## 진행 제안 순서
1. U1 설정 버튼 + U6 버튼 3종 고정: 작고 효과 큼, 반나절
2. U4 홈 3단 구조 + U3 안내 문장 줄이기: 후보 목업 2~3개를 먼저 보여 주고 고르기
3. U2 손그림 아이콘 30개 + U7 레시피 일러스트: 가장 큼. 캐릭터 최종 그림과 함께 결정(D8)
