## 🟠 2. "기억하는 AI"인데 기억을 덜 씀 — ✅ 2026-11-18 반영

| # | 빠진 것 | 왜 중요한가 |
|---|---|---|
| M1 ✅ | **좋아하는 음식**을 입력받지만 추천에 안 씀 | 음식 이름끼리 비교(+20). 재료 이름을 적었을 때만 재료로 비교 |
| M2 ✅ | **요리 실력**이 기본 레시피 추천에 반영 안 됨 | 초보: 보통 −12, 어려움 −35, 쉬움 +5('초보도 쉬워요') |
| M3 ✅ | 요리 후 **"맛있었어요/별로"** 피드백이 없음 | 요리 완료에 😋🙂😕. 최근 평가 😋 +15~24('전에 맛있다고 한 메뉴'), 😕 −40 |
| M4 ✅ | **남은 음식(2인분 만들고 1인분 먹음)** 을 기록 안 함 | 남은 양 → 냉장고 '남은 음식' 칸(기한은 사용자가 고름) → 홈 제안 1순위 → '한 끼 먹기'로 식사 기록 |
| M5 ✅ | 추천 점수가 왜 그렇게 나왔는지 **한곳에 모여 있지 않음** | logic/recommend.ts 한곳에서 점수·이유 계산, 홈·요리·식단·제안이 같이 씀 |

## 점검 중 추가로 찾아 고친 것
- '좋아하는 음식: 계란말이'가 계란이 들어간 비빔밥까지 '좋아하는 음식'으로 표시 → 음식 이름 기준으로 수정
