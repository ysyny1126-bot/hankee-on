# 한끼온 화면 설계 v2 (인터뷰 결정 · 2026-11-18)

원칙: **글자 대신 그림·숫자.** 문장은 한 줄 이하. 설명·근거는 기본으로 숨긴다.

## 하단 탭

```
🧊 냉장고 · 🍳 요리 · ⊕ · 📒 기록 · 🙂 나
```

## 🧊 냉장고 (첫 화면)
- 맨 위: **AI 말풍선 1개** — 지금 가장 중요한 제안 하나 (예: "두부 내일까지! 된장찌개 어때요? ›"). 누르면 해당 레시피.
- 본문: **칸별 선반** 냉장 / 냉동 / 실온. 재료 = 아이콘 + D-day 색(오늘·지남 빨강, 1~2일 노랑).
- 재료를 누르면 **아래에서 작은 창**: 수량 −/+ · 소비기한 ✏️ · [다 먹음] [버림] · "이 재료로 → ○○ ›"

## 🍳 요리
- "오늘 뭐 먹지?" **추천 카드 3개** (그림 · 이름 · 시간 · 재료 보유 표시) + [다른 추천 보기]
- 주간 식단은 아래에 작게 유지 (빼지 않음)
- 레시피: 첫 화면은 **큰 그림 + 재료 체크리스트**(있음/없음 아이콘) + [부족한 것 장보기] + [요리 시작]
- [요리 시작] → **요리 모드**: 단계가 큰 글씨로 한 장씩, ‹ 이전 / 다음 ›. 마지막 장 = 재고 차감 확인 + 식사 기록 저장

## ⊕ (가운데 버튼)
누르면 4개 선택: 📷 냉장고 찍기 · 🍽️ 식사 찍기 · 🍜 음식 사진 → 레시피 · ✏️ 재료 직접 추가

## 📒 기록
- 위: 날짜 ‹ 11월 18일 ›
- **아침 · 점심 · 저녁 · 간식 칸**. 빈 칸 누르면 기록, 찬 칸은 사진/이모지 + 음식 이름만.

## 🙂 나
- 주간 리포트(차트) — **에너지·단백질 정도만**, 나트륨·당류 등 상세 영양은 시연에서 뺌
- 식생활 목표(진행 막대)
- 아낀 돈 · 버린 재료
- 장보기 목록
- 설정(⚙️) — 취향·알레르기·알림·개인정보·데이터

## 온보딩
- **1화면**: 알레르기 칩 + 동의 한 번. 이름·예산·조리 시간은 나중에 설정에서.

## 유지되는 원칙 (기획서)
- AI 인식 재료는 확인 후 등록 · 소비기한 추측 금지 · 영양값은 '추정' 표시(작은 배지 하나로)
- 일간·월간 리포트는 유지하되 '나' 탭에서는 주간이 기본
