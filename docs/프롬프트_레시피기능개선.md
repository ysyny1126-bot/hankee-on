# 레시피 기능 개선 목록 + 실행 프롬프트

> 2026-11-25 작성. 사용자 지적: 메뉴 검색에 '마파투부'를 쳐도 아무것도 안 뜸.
> 원인 확인: ① 검색이 글자가 **정확히 포함**될 때만 찾음(오타·띄어쓰기·비슷한 말 못 찾음) ② 마파두부 레시피 자체가 없음(기본 레시피 69개) ③ 결과가 없을 때 대안이 'AI로 만들기' 버튼 하나뿐인데, AI가 꺼져 있거나 혼잡하면 막다른 길.

## 개선 목록

### A. 찾기 — "검색하면 뭐라도 나온다"
| # | 개선 | 내용 | 크기 |
|---|---|---|---|
| R1 | ✅ **오타·띄어쓰기에 강한 검색** | 띄어쓰기 무시, 한 글자 틀려도 찾기(편집 거리 1~2), 초성 검색(ㅁㅍㄷㅂ), 받침 유사(투/두) | 작음 |
| R2 | ✅ **같은 음식 다른 이름** | 별칭 표: 마파두부=마파 두부, 제육=돼지불고기, 계란=달걀, 떡볶이=떡뽁이 등. 레시피마다 `aliases` | 작음 |
| R3 | ✅ **결과 없을 때 막다른 길 없애기** | ① "혹시 ○○?" 가장 가까운 이름 제안 ② 같은 종류·재료가 겹치는 비슷한 메뉴 3개 ③ AI가 켜져 있으면 'AI로 만들기', 꺼져 있으면 '재료로 찾기' | 작음 |
| R4 | ✅ **재료로 검색 결과에 이유** | "두부 들어가는 메뉴 12개 · 지금 바로 3개" | 작음 |

### B. 레시피 수와 정확도 — "흔한 메뉴는 다 있고, 믿을 수 있다"
| # | 개선 | 내용 | 크기 |
|---|---|---|---|
| R5 | **자취 인기 메뉴 30개 추가** | 마파두부·짜장밥·닭볶음탕(1인분)·순두부열라면·참치김치찌개·스팸마요덮밥 등. 기준: 식약처 레시피 DB에 있거나, 레시피 사이트 2~3곳 공통 범위(복사 금지) | 중간 |
| R6 | **레시피별 근거 표시** | `source`: 식약처 레시피DB / 사이트 비교 / 한끼온 작성. 화면 맨 아래 한 줄 | 작음 |
| R7 | **AI 레시피 안전장치** | AI가 만든 레시피도 점검 스크립트 규칙(재료↔순서·시간·양 범위·알레르기)을 통과해야 저장. 실패하면 '확인 필요' 표시 | 중간 |
| R8 | **사용자 오류 신고** | 레시피 화면 '이상한 점 알려 주기'(양이 이상해요·순서가 빠졌어요·시간이 달라요) → 기기에 기록, 리포트에 모음 | 작음 |

### C. 정보량 — "만들기 전에 궁금한 건 다 있다"
| # | 개선 | 내용 | 크기 |
|---|---|---|---|
| R9 | **1인분 비용** | 재료 사전 평균가로 "약 3,200원 · 내 냉장고 재료 쓰면 추가 800원" | 작음 |
| R10 | **필요한 도구** | 팬·냄비·전자레인지·에어프라이어만 / 칼 없이 가능 표시. 자취방 조건 필터 | 작음 |
| R11 | **흔한 실수·성공 팁** | 단계마다 '이것만 조심'(예: 마늘은 약불, 계란은 마지막) 1줄 | 중간 |
| R12 | **맛 조절** | 맵기·짠맛 조절(고춧가루 0.5→0 등), 아이·다이어트 버전 한 줄 | 중간 |
| R13 | **영양 근거 확대** | 식약처 영양 DB 미연결 36개를 재료별 영양 합산으로 추정(근거: 재료 단위 영양, '계산값' 표시) | 중간 |

### D. 실사용자에게 유용 — "혼자 사는 사람의 진짜 고민"
| # | 개선 | 내용 | 크기 |
|---|---|---|---|
| R14 | **설거지·조리 부담 표시** | 그릇·도구 수로 '설거지 적음' 배지, 원팬·전자레인지 요리 모아보기 | 작음 |
| R15 | **두 번 먹기 설계** | 2인분 만들어 내일 다르게 먹기(카레 → 카레우동) 연결 레시피 | 중간 |
| R16 | **최근 만든 것·즐겨찾기 빠른 다시 만들기** | 메뉴 탭 위 '또 만들기' 줄(지난번 메모·평가 함께) | 작음 |
| R17 | **장보기 1번에 3끼** | 이 레시피와 재료가 많이 겹치는 다음 메뉴 2개 제안 | 중간 |

**하지 않을 것**: 커뮤니티·댓글·랭킹, 레시피 사이트 글·사진 복사, 확인 안 된 건강 효능 문구, 새 탭.

## 실행 프롬프트
```
한끼온(~/Desktop/창업아이템/hankee-on) 레시피 기능 개선이야. docs/프롬프트_레시피기능개선.md의 목록을 우선순위대로 진행해.

순서
1단계(검색, 오늘): R1 오타·띄어쓰기·초성 검색 → R2 별칭 → R3 결과 없을 때 대안 → R4
2단계(정확도): R6 근거 표시 → R7 AI 레시피 점검 → R8 오류 신고 → R5 인기 메뉴 30개(데이터 정확도 규칙 그대로)
3단계(정보): R9 비용 → R10 도구 → R14 설거지 부담 → R16 또 만들기
4단계(여유 있을 때): R11·R12·R13·R15·R17

규칙
- data-accuracy 스킬을 따른다: 새 레시피는 npm run check:data '문제 없음' 통과, 근거(source) 필수, 모르는 값은 지어내지 않는다.
- 검색 로직은 src/logic/search.ts 한 곳에 두고, 메뉴 탭·재료 검색·냉장고 털기가 함께 쓴다. 오타 허용은 짧은 단어(2글자 이하)엔 쓰지 않는다(엉뚱한 결과 방지).
- 화면은 늘리지 않는다: 새 탭·새 화면 없이 기존 레시피 화면·메뉴 탭에 줄 1개·버튼 1개.
- 새 라이브러리 설치 금지(검색은 직접 구현). 필요하면 먼저 묻기.
- 항목마다 step-finish 스킬: tsc·lint·check:data → hankee-sim-check 스크린샷 → 작업일지 → 커밋·푸시.
- 검색 확인 예: '마파투부'·'마파 두부'·'ㅁㅍㄷㅂ'·'떡뽁이'·'달걀볶음밥'이 원하는 메뉴를 찾는지 표로 기록.
```
